# Chinese serif font

Unmodified Noto Serif CJK SC Regular, bundled for reliable offline Chinese serif rendering.

Source: https://github.com/notofonts/noto-cjk/blob/main/Serif/OTF/SimplifiedChinese/NotoSerifCJKsc-Regular.otf
License: SIL Open Font License 1.1, included as OFL.txt. Copyright metadata is retained in the original font.

Registered through UIAppFonts. SwiftUI uses its PostScript name NotoSerifCJKsc-Regular with relativeTo text styles for Dynamic Type.
