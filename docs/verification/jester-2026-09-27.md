# Jester 中断与语言回归 · 2026-09-27

报告问题：`Should I leave my girl?`，APP 曾在显示半句后变为 “Connection unavailable”。

## 已确认的原因与证据边界

1. **错误标记丢失原因。** DirectJEVClient 原来将网络、超时、API 校验及本地组合异常全部转成相同 authoredFallback，ConversationView 再把所有 fallback 标成 Connection unavailable。因此该文案不能证明断网。旧版没有保存本次失败类别，不能倒推出用户那一条中断的具体原因。
2. **规则能把合法短句堵死。** Jester 的 minWords=6 原来同时是硬收尾门槛。`What is your fear` 是四词疑问句的合法前缀，问号却被禁止，且该语法分支无法继续，下一步候选为空。修复后允许 `What is your fear?` 完成。词数下限仍用于提示中的长度目标，语法完整性决定能否结束。
3. **仅按末词拦截标点与语法冲突。** 比如 `The door closes` 中 closes 是不及物动词，原 DANGLING 黑名单却不许句号。现由前缀语法判断是否可闭合，保留最大字数、最大选择数、重复限制与截止时间。
4. **风格相似主要证据是意象及组合方式。** 修改前实测出现抽象概念互相解释和同词回环。两角色可用副词分类都是 15 项；首次坏样本没有这些副词。副词数量不能解释该样本。强制凑词数则确实可能诱发添加尾部修饰。

## 改动

- Swift 桥接保留白名单错误类别，HTTP 保留状态码；generationStopReason 通过响应进入 ReadingTurn。标记区分网络中断、超时、密钥、限流、组句/校验失败。未识别错误使用通用 Reply unavailable，不推断为连接问题。
- 保留 accept 后 await onPartial 的流式顺序、pendingTurn、同 ID 提交和切换角色时的隔离；失败仍用完整角色保底替代未完成片段，且不将其加入后续模型上下文。
- Jester 补入 relationship、partner、love、reason、habit、choice、hurt、respect、honesty、feeling、conversation、obligation 等关系与选择词，以及 want、need、trust、choose、feel、stay。替换部分装饰性舞台/官僚意象，总容量仍为 **249 单词 + 5 标点 + END = 255**。
- Jester 内容词每条最多出现一次、连续形容词最多一个，简化尾部串接；增加普通反问和对照问句。提示优先回应具体问题，机锋可以来自对照或反问，不强制拟人化。
- 修正 between 需要两个并列对象的语法；what do you 引导的宾语前置问句不再要求额外宾语。
- Oracle、Stela、Fool 的词库内容未更改；共享语法收尾修正适用于三个逐词角色。未改视觉布局、动效与场景资源。

## 本地回归

- Python 语言测试 **32 通过**：新增短句收尾、不及物动词末尾、关系问句、对照问句、between 对象、内容词重复等覆盖。
- 跨端规则与服务合约 **8 通过**：JavaScript 候选集、Python 候选集和随 APP 打包的词库/提示一致。
- iOS Direct / Conversation / ReadingAPI **24 通过，4 条需显式启用的 live 测试跳过**。覆盖半句后网络失败与非法响应分别分类、一次失败不重试、超时与缺密钥、401、流式顺序、失败类别贯穿 store、切换角色隔离。
- 随机走查 300 条合法候选路径（每角色 100）无候选耗尽；这是结构检查，不是模型语言质量评分。

测试使用独立 JEV Conversation API 模拟器，没有占用样式任务的 iPhone Air。无密钥写入 APP 或仓库。

## 限制

没有复现用户历史上那一次半句失败的完整轨迹；已修复可确定的误报及语法死路，真实网络仍可能失败。风格已有针对性改进，但跨场景相关性和自然度仍需继续评测。保底始终标记 authored_fallback，不计为 Jev 生成成功。

最终 iOS 单题真实测试另行启用并通过，使用的是与仓库逐字节相同的最终 runtime；汇总及哈希见 [JSON 记录](jester-live-2026-09-27.json)。测试结果：`/private/tmp/jev-jester-final-tests.xcresult`、`/private/tmp/jev-jester-final-live.xcresult`。
