# 空间与转场 V4

2026-09-27。延续 [V3 的完整原图 + 连续深度](SPATIAL-V3.md)，根据真机体验反馈增强纵深。

## 更深的场景

- 归一化姿态在 ±10° 达到最大，之前为 ±12°。保持 60Hz 输入和 85ms 平滑。
- 逆重投影基线由宽 3% / 高 1.1% 提升到 5% / 2%，封顶 30pt / 20pt。
- 位移使用 `(depth - 1.3)`，整个深度范围位于屏幕后方；远景位移大于近景，界面停留在屏幕平面。
- 全景共享透视角度从 1.1° / 0.7° 提升到 3.2° / 2.2°，画布余量从 1.10 提升到 1.20，防止倾斜露边。
- 重新计算连续深度：对称坡度投影 320 次，目标坡度 0.012；原 RGB 不变。着色器逆求解 12 次，最大采样范围 40pt / 26pt。
- 最大对角姿态、包含 8-bit 纹理量化的收缩上界：Oracle 0.711、Stone 0.538、Jester 0.541，均低于 0.85 的验收阈值。

这仍是有限视角的图像重投影，不会生成被遮挡的背面。更强的效果通过连续几何和共享透视实现，不重新引入分离的物体平面。

## 入口视频

原始视频 `assets/video/entrance.mov` 原样打包到 `ios/JEV/Resources/Media/`，720×1280、30fps、5.0667秒。静音播放；实际播放完成通知触发 650ms 叠化，保留最后一帧直到 The Oracle 完全显现。取消原入口的模糊替代动画。

视频、静态入口与目标场景都使用全屏 GeometryReader 的确定尺寸。播放器预先挂载，第一帧可显示后再显现，避免黑色初始帧；播放期间可以 Skip。后台暂停、回前台续播；Reduce Motion 直接进入。10秒保护仅处理无法显示首帧，不截断正常播放的视频。
